# Number Guessing Game

A simple command-line number guessing game built with Python using GitHub Copilot.

## How to Play

1. Run the game with Python:
   ```bash
   python game.py
   ```
2. The program will generate a random number between 1 and 10.
3. Enter your guess at the prompt.
4. The game will tell you whether your guess is:
   - too low
   - too high
   - correct
5. Keep guessing until you find the right number.
6. The game will display the total number of attempts when you win.

## Features

- Random number generation from 1 to 10
- Feedback after each guess
- Tracks total attempts
- Simple command-line interface

## Example

```text
Welcome to the Number Guessing Game!
I'm thinking of a number between 1 and 10.
Enter your guess: 5
Too low! Try again.
Enter your guess: 8
Too high! Try again.
Enter your guess: 7
Correct! You guessed the number in 3 attempts.
```
